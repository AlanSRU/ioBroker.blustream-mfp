        Blustream SW-Series HDMI / HDBaseT Switchers — RS-232 / Telnet Command Reference

Applies to (adapter model keys):
  sw41hdbt (SW41HDBT)   — 4-way HDBaseT/HDMI input switch. SPACED dialect,
                          fixed-width INSTA/OUTSTA/CTRLSTA status tables
                          (parseC66Response). PoC verb "POC OUT xx" / "POC IN xx".
  sw41abv2, sw41ab8k, sw42da, sw21abv2, sw21abv3
                        — basic HDMI switchers. NO-SPACE dialect and, being single
                          HDMI output, they route with NO output index:
                              OUTFRyy   (e.g. OUTFR04)   — select source yy
                              OUTON / OUTOFF             — output on/off
                              OUT AUTO ON/OFF            — auto-switch (stays spaced)
                          (adapter: commandStyle 'nospace' + noOutputIndex).
                          STATUS reply is free-text, not the C-series table.

Connection: RS-232 57600 baud 8N1; Telnet TCP/IP. Terminator CR (0x0D).
The SW-AB manuals note spaces are optional: "OUTFR03" or "OUT FR 03" both work.

ADAPTER STATUS (v0.5.3): source selection (output.1.source) + auto-switch
implemented for all. SW41HDBT additionally has EDID (EDID xx DF/CP), per-output
& per-input CEC actions (OUT/IN xx CEC ...) and PoC wired. Scaling (OUT xx
SCALING) and SW-AB audio breakout are not yet wired. STATUS read-back IS parsed
(families `swHdbt` for SW41HDBT and `swBasic` for the SW-AB/DA switches),
grounded on the SW41HDBT, SW21AB-V3, SW41AB-8K and SW42DA-V2 captures.

                       SW41HDBT 
============= System Information Commands
?/HELP                      Print Help Information
STATUS                 Print System Status And Port Status
INSTA                  Print All Input Status
OUTSTA                 Print All Output Status
CTRLSTA                Print All Control Status
FWVERSION              Print FW version
============= System Control Commands
PON/OFF                Set System Power On Or Off
KEY ON/OFF             Set System Key Control On Or Off
IR ON/OFF              Set System IR Control On Or Off
OUT xx GUEST ON/OFF    Set System Guest Mode xx On Or Off
                       xx = 00: All HDBT output
                       xx = 01: HDBT output 1
IN xx GUEST ON/OFF     Set System Guest Mode xx On Or Off
                       xx = 00: All HDBT input
                       xx = 01: HDBT input 1
                       xx = 02: HDBT input 2
OUT xx IRHEXSEND b     Send Pronto Hex Code To Remote End
                       xx = 00: All HDBT output
                       xx = 01: HDBT output 1
                       b  = IR Value(Hex Format)
IN xx IRHEXSEND b      Send Pronto Hex Code To Remote End
                       xx = 00: All HDBT input
                       xx = 01: HDBT input 1
                       xx = 02: HDBT input 2
                       b  = IR Value(Hex Format)
RESET                  Reset System To Default Setting
                       (Type Yes To Confirm, No To Discard)
============= Input Port Control Commands
POC IN xx ON/OFF       Set POC Input xx On/Off
                       xx = [00]: All HDBT Input Ports, [01...02]: HDBT Input Po                                                                                                             rt
============= Output Port Control Commands
POC OUT xx ON/OFF      Set POC Output xx On/Off
                       xx=[00...01]: HDBT Output Port
OUT xx FR yy           Set Output xx From Input yy
                       xx = 00: All Outputs
                       xx = 01: All Outputs
                       yy = 01: HDBT input 1
                       yy = 02: HDBT input 2
                       yy = 03: HDMI input 3
                       yy = 04: HDMI input 4
OUT xx SWITCH yy       Set Output xx Switching To yy
                       xx = 00: All Output Ports
                       xx = 01: All Output Ports
                       yy = AUTO: Auto Switching On - Auto Mode
                       yy = MAN: Auto Switching Off - Manual Mode
AUTOTRG x              Set The Trigger Method x On Input To Perform Auto Switchi                                                                                                             ng
                       x = 1 - HDMI (5V)
                       x = 2 - HDMI (TMDS)
OUT xx SCALING ON/OFF  Set Output xx Scaling On Or Off
                       xx = [00...01]: HDBT Output Port
