============= System Information Command
?             Print Help Information
HELP          Print Help Information
STATUS        Print System Status And Port Status
FWVER         Print All Soft Version
============= System Control Command
PON           Power On, System Run On Normal State
POFF          Power Off, System Run On Power Save State
REBOOT        Set System And Network Reboot
IR ON/OFF     Set System IR Control On Or Off
KEY ON/OFF    Set System KEY Control On Or Off
LED xx yy     Set Power LED Light Up Time
          xx=PON: When Device Is Powered On
          xx=POFF: When Device Is Powered Off
          yy=OFF: Set Power LED To Always Off
          yy=15: Set Power LED To Auto Turn Off After 15sec
          yy=30: Set Power LED To Auto Turn Off After 30sec
          yy=60: Set Power LED To Auto Turn Off After 60sec
          yy=ON: Set Power LED To Always On
RSB x         Set RS232 Baud Rate To x bps
          x=[0:115200 1:57600, 2:38400, 3:19200, 4:9600]
RESET         Reset System To Default Setting
RESET ALL     Reset System And Network To Default Setting
(Should Type "Yes" To Confirm, "No" To Discard)
============= Input And Output Port Control Command
MODE oo       Set Device mode
       oo=[00]: Matrix mode
       oo=[01]: VideoWall mode
       oo=[02]: Multiview mode
OUT oo ON/OFF Set Output On Or Off
OUT oo FR ii  Set Output:oo From Input:ii
       oo=[00]: Select All Output Port
       oo=[01...04]: Select One Output Port
       ii=[01...04]: Select One Input Port
OUT xx BRIGHTNESS yy Set Output xx Brightness To yy
       xx=[01...04]: Select One Output Port
       yy=[0...255]: Brightness Value
OUT xx SATURATION yy Set Output xx Saturation To yy
       xx=[01...04]: Select One Output Port
       yy=[0...255]: Saturation Value
OUT xx CONTRAST yy Set Output xx Contrast To yy
       xx=[01...04]: Select One Output Port
       yy=[0...255]: Contrast Value
OUT xx HUE yy Set Output xx Hue To yy

       yy=[0...255]: Hue Value
OUT oo SCALING yy Set Output Video Mode yy

AUDIO xx FR yy Set Audio Output xx From Input yy

        xx = [05]: Analogue and Optical Audio Output
        yy = [01-04] : Audio From HDMI Input 1-4
        yy = [05] : Analogue Audio Input
AUDOUT xx mm  Turn Mute On/Off On Output xx
        mm = On
        mm = Off
        xx = 00 : All Outputs
        xx = [01-04] : HDMI Output 1 - 4
        xx = [05]: Analogue and Optical Audio Output
AUDIN GAIN vv yy Set Input: xx Gain To yy
        vv=[L, R or LR] This Is Optional. If L Or R Is Not Specified
        Then Both Channels Are Adjusted
        yy=[-12...40]: Gain Value (dB) (Step=0.5)

============= Video Wall Control Command
VW PRESET pp NAME name  Set Video Wall Name to name
       pp=[01..8]: Select Preset Index
       name: Max 16 char
VW LAYOUT xx FR ii  Set Output Layout Index:xx From Input:aa/bb/cc/dd
       xx=[01..12]: Select Layout Index
       ii=[01...04]: Select One Input Port For Video Wall Source
VW PRESET pp LAYOUT USER <x1,y1,h1,v1,r1> <x2,y2,h2,v2,r2> <x3,y3,h3,v3,r3> <x4,y4,h4,v4,r4> FR ii
       Set Preset:pp Layout To User Defined:<x,y,h,v,r> From Input:aa/bb/cc/dd
       x=[00...4095]: X Coordinate Of Window 1/2/3/4 Top-left Corner
       y=[00...2159]: Y Coordinate Of Window 1/2/3/4 Top-left Corner
       h=[00...4095]: The Horizontal Size Of Window 1/2/3/4
       v=[00...2159]: The Vertical Size Of Window 1/2/3/4
       r=[00..360]: The Angle Rotation Of Window 1/2/3/4
       ii=[01...04]: Select One Input Port For Video Wall Source
VW PRESET pp STATUS Print Preset pp Config Status
       pp - 1~8
VW PRESET pp SAVE   Save Current Config To Preset:pp
       pp=[01..08]: Select Preset Index
VW PRESET pp APPLY  Apply Preset:pp Config
       pp=[01..08]: Select Preset Index
VW LAYOUT xx USER <x1,y1,w1,h1,r1>
       Set Output:xx Layout To User Defined:<x,y,h,v>
       x=[00...4095]: X Coordinate Of Crop Window Top-left Corner
       y=[00...2159]: Y Coordinate Of Crop Window Top-left Corner
       h=[00...4095]: The Horizontal Size Of Crop Window
       v=[00...2159]: The Vertical Size Of Crop Window
       r=[00..360]: The Angle Rotation Of Crop Window
VW FR ii
       ii=[01...04]: Select One Input Port For Video Wall Source
VW AUDIO FR yy
       yy=[00]: Video Wall audio follow video Source
       yy=[01...04]: Video Wall audio set to HDMI 1 ~ 4
       yy=[05]: Video Wall audio set to analogue input
============= Multiview Control Command
MV mm WIN xx FR yy
       Set Multiview mm WIN xx From yy
       mm=[01..02]: Select Multiview Index
       xx=[00]: Select All Window
       xx=[01..04]: Select Window number 1 ~ 4
       yy=[01...04]: Select One Input Port 1 ~ 4
MV mm LAYOUT xx FR aa bb cc dd
       Set Output Layout Index:xx From Input:aa/bb/cc/dd
       mm=[01..02]: Select Multiview Index
       xx=[01..5]: Select Layout Index
       aa=[01...04]: Select One Input Port For Window 1 Source
       bb=[01...04]: Select One Input Port For Window 2 Source
       cc=[01...04]: Select One Input Port For Window 3 Source
       dd=[01...04]: Select One Input Port For Window 4 Source
       Note: aa, bb, cc, dd are optional
MV mm LAYOUT USER <x1,y1,h1,v1> <x2,y2,h2,v2> <x3,y3,h3,v3> <x4,y4,h4,v4> FR aa bb cc dd
       Set Output Layout To User Defined:<x,y,h,v> From Input:aa/bb/cc/dd
       mm=[01..02]: Select Multiview Index
       x=[00...4095]: X Coordinate Of Window 1/2/3/4 Top-left Corner
       y=[00...2159]: Y Coordinate Of Window 1/2/3/4 Top-left Corne
       h=[00...4095]: The Horizontal Size Of Window 1/2/3/4
       v=[00...2159]: The Vertical Size Of Window 1/2/3/4
       aa=[01...04]: Select One Input Port For Window 1 Source
       bb=[01...04]: Select One Input Port For Window 2 Source
       cc=[01...04]: Select One Input Port For Window 3 Source
       dd=[01...04]: Select One Input Port For Window 4 Source
       Note: aa, bb, cc, dd are optional
MV mm AUDIO FR yy    Set Output Audio From Input yy
       mm=[01...04]: Select One Output Port
       yy=[01...04]: Select One Input Port
       yy=[05]: Analogue Input
MV mm PRESET pp NAME name   Set Multiview Name to name
       mm=[01..02]: Select Multiview Index
       pp=[01..8]: Select Preset Index
       name: Max 16 char
MV mm PRESET pp LAYOUT xx FR aa bb cc dd
       Set Preset:pp To Layout Index:xx From Input:aa/bb/cc/dd
       mm=[01..02]: Select mv Index
       pp=[01..08]: Select Preset Index
       xx=[01..05]: Select Layout Index
       aa=[01...04]: Select One Input Port For Window 1 Source
       bb=[01...04]: Select One Input Port For Window 2 Source
       cc=[01...04]: Select One Input Port For Window 3 Source
       dd=[01...04]: Select One Input Port For Window 4 Source
MV mm PRESET pp LAYOUT USER <x1,y1,h1,v1> <x2,y2,h2,v2> <x3,y3,h3,v3> <x4,y4,h4,v4> FR aa bb cc dd
       Set Preset:pp Layout To User Defined:<x,y,h,v> From Input:aa/bb/cc/dd
       mm=[01..02]: Select Multiview Index
       x=[00...4095]: X Coordinate Of Window 1/2/3/4 Top-left Corner
       y=[00...2159]: Y Coordinate Of Window 1/2/3/4 Top-left Corne
       h=[00...4095]: The Horizontal Size Of Window 1/2/3/4
       v=[00...2159]: The Vertical Size Of Window 1/2/3/4
       aa=[01...04]: Select One Input Port For Window 1 Source
       bb=[01...04]: Select One Input Port For Window 2 Source
       cc=[01...04]: Select One Input Port For Window 3 Source
       dd=[01...04]: Select One Input Port For Window 4 Source
MV mm PRESET STATUS Print Preset Config Status
MV mm PRESET pp SAVE Save Current Config To Preset:pp
       pp=[01..08]: Select Preset Index
MV mm PRESET pp APPLY  Apply Preset:pp Config
       pp=[01..08]: Select Preset Index
MV mm WIN ww FLIP xx Set Multiview Output mm Orientation to Flip xx
       mm=[01..02]: Select Multiview Index
       ww = 00 : All Windows
       ww = [01-04] : Window 1 - 4
       xx = 00 : Flip Off
       xx = 01 : Horizontal Flip
       xx = 02 : Vertital Flip
       xx = 03 : Horizontal & Vertical Flip
============= Network Control Command
NETSTA : Show NET Settings
NET DHCP ON/OFF : Set Auto IP(DHCP) On Or Off
NET IP xxx.xxx.xxx.xxx : Set IP Address
NET GW xxx.xxx.xxx.xxx : Set Gateway Address
NET SM xxx.xxx.xxx.xxx : Set Subnet Mask Address
NET TCPPORT xxxx : Set TCP/IP Port
NET TCPPORT ON/OFF: Set TCP/IP On Or Off
NET TN xxxx : Set Telnet Port
NET TN ON/OFF: Set Telnet On Or Off
NET WEB ON/OFF: Set Web Access On Or Off
NET HTTPS ON/OFF: Set Https Access On Or Off
NET RB : Set Network Reboot And Apply New Config!!!
NET DNS xxxx : Set DNS Domain Name To xxxx
