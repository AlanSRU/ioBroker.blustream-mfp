        Blustream CMX / MX HDMI Matrix — RS-232 / Telnet Command Reference

Applies to (adapter model keys): cmx42cs, cmx44cs (CMX44CS-V2), cmx44ab, cmx88cs,
cmx88ab, mx22ab8k (MX22AB-8K), mx44abv2 (MX44AB-V2).

These are HDMI (non-HDBaseT) crosspoint matrices with analogue L/R + optical (S/PDIF)
audio breakout on every output. No PoC (no HDBaseT). Presets, EDID and a web GUI.

Dialect: NO-SPACE (adapter commandStyle = 'nospace'):
  OUTxxON / OUTxxOFF       Set output xx on/off      (e.g. OUT01ON)
  OUTxxFRyy               Route input yy to output xx (e.g. OUT01FR04)
    xx = zone/output 01..N (00 = all)
    yy = source input 01..N
Verbatim from the CMX88CS/CMX88AB manuals (RS-232 & Telnet Commands, "How the
string should look is as follows OUT01ON").

Connection:
  RS-232: 57600 baud, 8N1. DB9.
  Telnet: TCP/IP (RJ45). Default IP 192.168.0.200 when no DHCP server present.
  Command terminator: CR (0x0D).

Core commands (verified from manuals):
  STATUS            Print system/port status (free-text: "zones on, type of
                    connection etc" — NOT the C-series fixed-width table).
  PON / POFF        Power on / off
  OUTxxON / OUTxxOFF
  OUTxxFRyy
  EDIDxxCPyy        Copy EDID from output yy to input xx (xx/yy = 01..N or ALL)
  EDIDxxDFzz        Set input xx EDID to default profile zz
  IRON / IROFF      System IR control on/off       (MX44AB-V2 manual)
  KEYON / KEYOFF    Front-panel key lock on/off
  BEEPON / BEEPOFF  Onboard beep on/off
  DBGON / DBGOFF    Debug mode
  RESET             Reset to factory defaults

Presets: 8 custom presets via the web GUI / API (recall + save).

ADAPTER STATUS (v0.5.3): routing + output enable + presets + per-input EDID
(EDIDxxDF/CP — unspaced here, per commandStyle) implemented (write path,
command-doc verified). CMX/MX audio
breakout FOLLOWS the HDMI video output and has NO separate API command, so no
audio states are created. STATUS read-back IS parsed (family `hdmi`), grounded
on the CMX44CS-V2 STATUS/INSTA/OUTSTA captures in "Status Feedback/". See MODEL-EXPANSION-PLAN.md.
